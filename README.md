# Token Launch Radar

A Node 22 program that reads the sealed DefiLlama snapshot (758 protocols, 14 Nov 2026), fits a value model on the 128 traded tokens in it, and ranks 198 protocols that record no token — the 40 watchlist protocols plus the 158 early pre-token protocols below the $50M floor with the most TVL — by implied value. A protocol records no token only when both its gecko_id and symbol are null (342 of 758); the 416 that record a token include 144 carrying a recorded market cap, listed on the dashboard with their realised values.

**Model:** log market cap on log TVL plus TVL curvature `(log TVL)^2`. Candidate terms (7-day growth, no-token age, category median) were tested and dropped: each raised the held-out miss in at least one test. Held-out evidence, computed by the program and shown on the dashboard: leave-one-out miss x3.38 and walk-forward miss x2.61 (earlier-listed tokens price later-listed ones), a leave-one-out P25–P75 range whose walk-forward coverage is 52.1% of later-listed peers (leave-one-out coverage 50.8%), and a token-odds Brier score of 0.220 against a base rate of 0.250. Token odds are the peers' own record — the share of protocols of the same no-token age that record a token. Implied value = value if a token launches × token odds. Every row carries a concrete 5-step farm plan with costs and times, written per category for a $1,000 reference deposit, and a FARM / MARGINAL / SKIP verdict with net value after fees and net value per hour. At the stated economics no row clears the $25/hour FARM bar, so the honest verdict split is 0 FARM / 4 MARGINAL / 194 SKIP; off-list rows (wrapped, staked or bridged products and custodial exchanges) are never FARM. The dashboard reads verdicts from board.json and scales them with the same formula only when the deposit control moves. Verification numbers only prove the program runs; they do not predict a final rank.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>`. Standard library only, no network at run time.
